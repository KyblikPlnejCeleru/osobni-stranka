# Zpráva o přístupnosti

Stránka `Osobní stránka – potok` je optimalizovaná pro WCAG 2.2 úroveň AA.

## Použité postupy a nástroje

- Ruční kontrola klávesnicí (Tab, Shift+Tab, Enter), přiblížení 200 % a 400 %.
- Chrome DevTools: Lighthouse (Accessibility), Rendering (emulace media features).
- W3C HTML validator, WAVE (doplní se po spuštění).
- Kontrola kontrastu a pořadí nadpisů.
